Help & Instructions

Follow these steps to use the ATS Resume Tracker effectively:

  • Enter Job Description: Paste or type the job description in the left textarea (up to 5000 words).
  • Upload Resume: Select a text-based PDF resume (max 5MB) using the file input on the right.
  • Analyze: Click the "Analyze Resume" button to process your inputs.
  • View Results: Check the results section for:
    • Match score (percentage of keyword overlap).
    • Extracted keywords from job description (below job description box).
    • Extracted keywords from resume (below resume upload box).
    • Missing keywords from the job description.
    • AI-powered analysis with suggestions.
    • Extracted requirements (Technical Skills, Soft Skills, Tools).
  • Tips: Ensure your resume is text-based (not scanned) and the job description is clear and detailed.
